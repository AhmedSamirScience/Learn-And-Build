## 🧠 Summary Definitions

| Term         | Description |
|--------------|-------------|
| **Language** | The syntax and rules used to write software (e.g., Java, Python) |
| **Framework**| A reusable set of libraries or tools that provides structure (e.g., Spring, Django) |
| **Runtime**  | The engine that executes the code written in a language (e.g., JVM, Node.js) |
| **Platform** | A comprehensive ecosystem of tools, libraries, and runtime to build and run applications (e.g., .NET, Android) |
| **Environment** | The configuration in which a system runs (e.g., dev, staging, prod) |

## 🛠️ Why This Matters

Understanding these terms:
- Enhances clarity in team communication
- Improves architectural decision-making
- Helps in choosing the right tech stack
- Avoids misinterpretation when reading documentation or interviewing
